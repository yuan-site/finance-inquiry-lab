# 投資理財的探究與實作

繁體中文投資理財教學網站。品牌：依使用者參考圖改為亮藍、橘色、冷白；完成狀態獨立使用綠色。

## 本機預覽

使用靜態 HTTP 伺服器提供 ``，不需要安裝套件或建置。

```sh
python -m http.server 4173 
```

## 內容與功能

- 7 個主題模組、59 個知識點、23 個案例導讀。
- 每個知識點含詳細分節解說、選擇性的螢光筆重點、相應實作步驟、結果與驗算、延伸練習、單題測驗及筆記。
- 3 條學習路徑、21 項函數／公式、6 組可填寫提問模板。
- 儲蓄、貸款、現金流、風險相關性與圖表實驗工具。
- 日週 K、SMA、MACD、KD、RSI、布林及合成資料回測。
- 搜尋、收藏、進度、筆記，以及 JSON 備份匯出／合併匯入。
- 學習資料只保存在目前瀏覽器；沒有帳號、AI API 或即時行情。

## 檔案

- `content.js`：知識、案例、函數與模板內容。
- `lesson-details.js`：第一人稱詳細解說、對應實作、專屬案例步驟與教學資料表。
- `math.js`：計算、指標、合成資料與回測。
- `app.js`：路由、畫面與互動。
- `style.css`：桌面與手機版樣式。
- `verify.mjs`：財務計算、指標範圍與內容關聯檢查。

執行 `node verify.mjs` 驗證計算與內容結構。
