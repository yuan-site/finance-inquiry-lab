## 網站內容

7 個主題模組、59 個知識點、23 個案例導讀、21 項公式速查、6 組提問模板，以及儲蓄、貸款、現金流、相關性和圖表工具。

此版本保存目前正式網站內容；尚未逐段收錄原始掃描教材所有文字、圖片及完整對話。圖表實驗使用明確標註的合成資料。

## GitHub Pages

網站是純靜態檔案，不需安裝套件或建置。
將本資料夾內容放在儲存庫 main 分支根目錄，在 Settings → Pages 中選擇 Deploy from a branch，分支 main，資料夾 /(root)，然後 Save。

入口為 index.html；其餘 CSS、JavaScript 與 favicon.svg 必須一起保留。
.nojekyll 用於直接發布靜態檔案。路由採用 #/，支援儲存庫子路徑。

## 個人紀錄與字型

筆記、收藏與進度保存在使用者的瀏覽器。更換網站網址前，可於「我的學習」匯出，再在新網址匯入。
Google Fonts 需網路，無法載入時使用系統字型。核心課程與工具無需伺服器、資料庫或付費 API。
